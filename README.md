# AlightFree frontend — Vercel

Template frontend statis menggunakan HTML, CSS, dan JavaScript biasa. Tidak membutuhkan build command atau environment variables.

## Deploy ke Vercel
1. Ekstrak ZIP ini.
2. Upload folder ke repository GitHub.
3. Di Vercel, pilih **Add New → Project** lalu import repository.
4. Framework Preset: **Other**.
5. Build Command: kosongkan; Output Directory: `.`.
6. Deploy.

## Catatan
- Ini merupakan rekreasi frontend berdasarkan informasi publik, bukan salinan source code asli.
- Tidak ada backend, database, atau aktivasi lisensi yang terhubung.
- Jangan menambahkan form untuk mengumpulkan password, OTP, magic link, atau token login pengguna.
- Tombol utama diarahkan ke situs resmi Alight Motion.
